# Referência de interface v0.33

`ui-batalha-v0.33.png` é a imagem enviada pelo criador para orientar o campo, o foco entre cartas, o uso de habilidades, os vínculos e as barras de Vida. É uma referência de apresentação. Os números impressos nela não substituem o balanceamento aprovado da v0.32.0. A implementação mantém as artes oficiais de cada carta e usa comandos adaptados às regras existentes.
