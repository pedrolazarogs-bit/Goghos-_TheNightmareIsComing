# Interface da noite — v0.30.0

22 ícones SVG e dois ornamentos desenhados em código para o jogo, sem dependências externas, fontes ou scripts. A arte oficial dos personagens e a logo não foram alteradas.

- `icons/`: ações, navegação e consultas em ferro, marfim e latão, com detalhes rosa, lavanda e verde espectral.
- `arch.svg`: arco pontiagudo discreto para o cenário do menu e da abertura.
- `sigil.svg`: ornamento simétrico em losangos.

Os antigos kits ficam preservados como referências. Os novos arquivos são somente apresentação e não contêm atributos nem regras de combate.
