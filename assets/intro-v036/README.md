# Abertura enviada pelo criador

Os cinco arquivos foram extraídos, sem conversão ou alteração, de **GOGHOS, tela de carregamento.html**. O manifesto registra o SHA-256 do HTML recebido e de cada arquivo extraído. A fonte German Beauty é idêntica à já utilizada no jogo.

A animação Canvas 2D está em `js/ui/loading_screen.js`. As duas camadas da marca, o monstro, a música, os movimentos e as batidas vêm do arquivo recebido. A integração utiliza o carregamento real do jogo; a tela fictícia e o carregamento aleatório de demonstração não fazem parte do projeto.
